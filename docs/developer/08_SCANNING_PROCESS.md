# Процесс сканирования и сбора данных о приложениях

## Обзор

FAgent собирает данные о приложениях из трёх источников:
1. **SVC** - Solaris Service Management Facility (Java/Tomcat приложения)
2. **Docker** - Docker контейнеры
3. **Eureka** - Service Discovery Registry (Spring Boot приложения)

---

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          GET /app REQUEST                                    │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                       DiscoveryManager.run_discovery()                       │

│   Последовательно вызывает discover() на каждом загруженном плагине         │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
         ┌──────────────────────────┼──────────────────────────┐
         │                          │                          │
         ▼                          ▼                          ▼
┌─────────────────────┐   ┌─────────────────────┐   ┌─────────────────────┐
│  SVCAppDiscoverer   │   │  DockerDiscoverer   │   │  EurekaDiscoverer   │
│                     │   │                     │   │                     │
│  Источник: SVC      │   │  Источник: Docker   │   │  Источник: Eureka   │
│  Solaris services   │   │  daemon             │   │  REST API           │
└─────────┬───────────┘   └─────────┬───────────┘   └─────────┬───────────┘
          │                         │                         │
          ▼                         ▼                         ▼
┌─────────────────────┐   ┌─────────────────────┐   ┌─────────────────────┐
│ List[ApplicationInfo│   │ List[ApplicationInfo│   │ List[ApplicationInfo│
│   source="svc"]     │   │   source="docker"]  │   │   source="eureka"]  │
└─────────┬───────────┘   └─────────┬───────────┘   └─────────┬───────────┘
          │                         │                         │
          └─────────────────────────┼─────────────────────────┘
                                    │
                                    ▼
                    ┌───────────────────────────────┐
                    │  Объединение всех результатов │
                    │  в единый список              │
                    └───────────────────────────────┘
                                    │
                                    ▼
                    ┌───────────────────────────────┐
                    │  Группировка по source:       │
                    │  - docker → "docker-app"      │
                    │  - svc    → "site-app"        │
                    │  - eureka → (не включается)*  │
                    └───────────────────────────────┘
                                    │
                                    ▼
                    ┌───────────────────────────────┐
                    │       JSON Response           │
                    └───────────────────────────────┘

* Eureka данные используются для обогащения Docker контейнеров,
  а не выводятся отдельно
```

## 1. Сканирование SVC приложений (Solaris)

### Источники данных

| Данные | Источник | Команда/Путь |
|--------|----------|--------------|
| Список приложений | Файловая система | Директории в `/site/app/` |
| Статус, время запуска | svcs | `svcs -Ho state,stime {app_name}` |
| PID процесса | svcs | `svcs -p -H {app_name}` |
| Порт (Tomcat) | Файл конфигурации | `/site/app/{app}/conf/server.xml` |
| Порт (fallback) | netstat | `netstat -an -P tcp` |
| Артефакт (war/jar) | Файловая система | Симлинки в `/site/share/htdoc/` |
| Версия | Regex парсинг | Из пути артефакта |
| Путь к логам | Файловая система | `/site/app/{app}/logs/` (симлинк) |

### Детальная схема сканирования SVC

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     SVCAppDiscoverer.discover()                              │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  1. ПОЛУЧЕНИЕ СПИСКА ПРИЛОЖЕНИЙ                                              │
│                                                                              │
│     app_names = [dir.name for dir in /site/app/ if dir.is_dir()]            │
│                                                                              │
│     Пример: ["myapp", "billing", "auth-service", "FAgent"]                  │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  FOR EACH app_name IN app_names:                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
        ┌───────────────────────────┴───────────────────────────┐
        │                                                       │
        ▼                                                       │
┌───────────────────────────────────────────────────────┐       │
│  2. ПОЛУЧЕНИЕ СТАТУСА (svcs)                          │       │
│                                                       │       │
│  Команда: svcs -Ho state,stime {app_name}             │       │
│                                                       │       │
│  Пример вывода: "online         Oct_31"               │       │
│                                                       │       │
│  Парсинг:                                             │       │
│    status = "online"                                  │       │
│    start_time = "Oct_31"                              │       │
│                                                       │       │
│  Возможные статусы:                                   │       │
│    - online      (приложение работает)                │       │
│    - offline     (остановлено)                        │       │
│    - maintenance (в обслуживании)                     │       │
│    - disabled    (отключено)                          │       │
│    - unknown     (ошибка получения)                   │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  3. ПОЛУЧЕНИЕ PID ПРОЦЕССА (svcs -p)                  │       │
│                                                       │       │
│  Команда: svcs -p -H {app_name}                       │       │
│                                                       │       │
│  Пример вывода:                                       │       │
│    "online         Oct_31   -"                        │       │
│    "               Oct_31 12345 java"                 │       │
│                                                       │       │
│  Алгоритм парсинга:                                   │       │
│    1. Пропустить строки без отступа (заголовки)       │       │
│    2. Найти строку с отступом                         │       │
│    3. Разбить по пробелам                             │       │
│    4. Найти первое число = PID                        │       │
│                                                       │       │
│  Результат: pid = 12345                               │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  4. ПОЛУЧЕНИЕ ПОРТА                                   │       │
│                                                       │       │
│  Приоритет 1: Парсинг server.xml (Tomcat)             │       │
│  ─────────────────────────────────────────            │       │
│  Путь: /site/app/{app}/conf/server.xml                │       │
│                                                       │       │
│  Ищем: <Connector port="8080" protocol="HTTP/1.1"     │       │
│                                                       │       │
│  Regex: <Connector[^>]*port=["'](\d+)["'][^>]*        │       │
│         protocol=["']HTTP                             │       │
│                                                       │       │
│  Приоритет 2: netstat (fallback)                      │       │
│  ─────────────────────────────────────────            │       │
│  Команда: netstat -an -P tcp                          │       │
│                                                       │       │
│  Ищем строки с LISTEN, извлекаем порт                 │       │
│  Проверяем типичные порты: 8080, 8443, 9090...        │       │
│                                                       │       │
│  Результат: port = 8080 (или None)                    │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  5. ПОИСК АРТЕФАКТА (war/jar)                         │       │
│                                                       │       │
│  Шаг 1: Проверка name_mapping                         │       │
│  ─────────────────────────────────────────            │       │
│  Файл: app_name_mapping.json                          │       │
│  {"myapp": "my-application-dist"}                     │       │
│                                                       │       │
│  Если есть маппинг:                                   │       │
│    - Относительный: ищем в /site/share/htdoc/         │       │
│    - Абсолютный путь: используем напрямую             │       │
│                                                       │       │
│  Шаг 2: Поиск симлинка в htdoc_root                   │       │
│  ─────────────────────────────────────────            │       │
│  Проверяем в порядке приоритета:                      │       │
│    1. /site/share/htdoc/{name}.war  (симлинк)         │       │
│    2. /site/share/htdoc/{name}.jar  (симлинк)         │       │
│    3. /site/share/htdoc/{name}/     (директория)      │       │
│                                                       │       │
│  Шаг 3: Resolve симлинка                              │       │
│  ─────────────────────────────────────────            │       │
│  symlink.resolve() → реальный путь                    │       │
│                                                       │       │
│  Пример:                                              │       │
│    /site/share/htdoc/myapp.war →                      │       │
│    /site/share/htdoc/20250101_120000_myapp-1.2.3/     │       │
│      myapp-1.2.3.war                                  │       │
│                                                       │       │
│  Результат:                                           │       │
│    artifact_path = Path("/.../myapp-1.2.3.war")       │       │
│    artifact_type = "war"                              │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  6. ИЗВЛЕЧЕНИЕ ВЕРСИИ                                 │       │
│                                                       │       │
│  Regex паттерн: (\d+\.\d+\.[\d\.]+)                   │       │
│                                                       │       │
│  Примеры:                                             │       │
│    /path/myapp-1.2.3.war        → "1.2.3"             │       │
│    /path/20250101_app-2.0.0/... → "2.0.0"             │       │
│    /path/app-1.0.0-SNAPSHOT.jar → "1.0.0"             │       │
│                                                       │       │
│  Результат: version = "1.2.3"                         │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  7. СБОР МЕТАДАННЫХ                                   │       │
│                                                       │       │
│  metadata = {                                         │       │
│    "source": "svc",                                   │       │
│    "pid": 12345,                                      │       │
│    "port": 8080,                                      │       │
│    "log_path": "/var/log/myapp/",  # resolve симлинка │       │
│    "distr_path": "/site/share/.../myapp-1.2.3.war",   │       │
│    "artifact_size_bytes": 52428800,                   │       │
│    "artifact_size_mb": 50.0,                          │       │
│    "artifact_type": "war",                            │       │
│    "app_path": "/site/app/myapp"                      │       │
│  }                                                    │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  8. СОЗДАНИЕ ApplicationInfo                          │       │
│                                                       │       │
│  ApplicationInfo(                                     │       │
│    name = "myapp",                                    │       │
│    version = "1.2.3",                                 │       │
│    status = "online",                                 │       │
│    start_time = "Oct_31",                             │       │
│    metadata = {...}                                   │       │
│  )                                                    │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        └───────────────────────────────────────┘
                                    │
                                    ▼
                    ┌───────────────────────────────┐
                    │  return List[ApplicationInfo] │
                    └───────────────────────────────┘
```

## 2. Сканирование Docker контейнеров

### Источники данных

| Данные | Источник | Метод |
|--------|----------|-------|
| Список контейнеров | Docker API | `client.containers.list()` |
| ID, имя, образ, статус | Container object | `.id`, `.name`, `.image`, `.status` |
| PID процесса | Container attrs | `.attrs['State']['Pid']` |
| Время запуска | Container attrs | `.attrs['State']['StartedAt']` |
| Порты | Container object | `.ports` |
| docker-compose путь | Labels | `com.docker.compose.project.config_files` |
| Eureka данные | Eureka API | Обогащение по IP:port |

### Детальная схема сканирования Docker

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      DockerDiscoverer.discover()                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  1. ПРОВЕРКА ДОСТУПНОСТИ DOCKER                                              │
│                                                                              │
│     if not self.enabled or not self.client:                                 │
│         return []                                                            │
│                                                                              │
│     Проверяется:                                                             │
│     - DOCKER_DISCOVERY_ENABLED=true                                          │
│     - Docker daemon доступен (ping)                                          │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  2. ПОЛУЧЕНИЕ СПИСКА КОНТЕЙНЕРОВ                                             │
│                                                                              │
│     containers = client.containers.list(all=False)                          │
│                                                                              │
│     all=False → только запущенные контейнеры                                 │
│     all=True  → все контейнеры (включая остановленные)                       │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  3. ПОЛУЧЕНИЕ IP СЕРВЕРА                                                     │
│                                                                              │
│     server_ip = _get_server_ip()                                            │
│                                                                              │
│     Метод: создать UDP socket, подключиться к 8.8.8.8:80,                   │
│            получить локальный IP из socket.getsockname()[0]                  │
│                                                                              │
│     Результат: "192.168.1.100"                                               │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  FOR EACH container IN containers:                                           │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
        ┌───────────────────────────┴───────────────────────────┐
        │                                                       │
        ▼                                                       │
┌───────────────────────────────────────────────────────┐       │
│  4. ИЗВЛЕЧЕНИЕ БАЗОВЫХ ДАННЫХ                         │       │
│                                                       │       │
│  container_id = container['ID']                       │       │
│    → "abc123def456..."                                │       │
│                                                       │       │
│  container_name = container['Names'].lstrip('/')      │       │
│    → "my-app"                                         │       │
│                                                       │       │
│  image_full = container['Image']                      │       │
│    → "registry.example.com/my-app:v1.2.3"            │       │
│                                                       │       │
│  status_string = container['Status']                  │       │
│    → "running" или "Up 2 hours"                       │       │
│                                                       │       │
│  ports_string = container['Ports']                    │       │
│    → "0.0.0.0:8080->8080/tcp"                        │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  5. ПАРСИНГ ОБРАЗА И ТЕГА                             │       │
│                                                       │       │
│  image, tag = parse_image_tag(image_full)             │       │
│                                                       │       │
│  Примеры:                                             │       │
│    "nginx:latest"                                     │       │
│      → image="nginx", tag="latest"                    │       │
│                                                       │       │
│    "registry.com:5000/app:v1.2.3"                    │       │
│      → image="registry.com:5000/app", tag="v1.2.3"   │       │
│                                                       │       │
│    "my-app" (без тега)                                │       │
│      → image="my-app", tag="latest"                   │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  6. ПАРСИНГ ПОРТА                                     │       │
│                                                       │       │
│  port = parse_port_mapping(ports_string)              │       │
│                                                       │       │
│  Примеры:                                             │       │
│    "0.0.0.0:8080->8080/tcp"                          │       │
│      → port = 8080 (host port)                        │       │
│                                                       │       │
│    "0.0.0.0:9090->8080/tcp"                          │       │
│      → port = 9090 (host port, не container port!)    │       │
│                                                       │       │
│    "8080/tcp" (без маппинга на хост)                  │       │
│      → port = None                                    │       │
│                                                       │       │
│  Если несколько портов - берётся первый               │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  7. ПОЛУЧЕНИЕ ДОПОЛНИТЕЛЬНЫХ ДАННЫХ                   │       │
│                                                       │       │
│  PID:                                                 │       │
│    pid = container.attrs['State']['Pid']              │       │
│    → 12345 (или 0 если контейнер остановлен)          │       │
│                                                       │       │
│  Время запуска:                                       │       │
│    start_time = container.attrs['State']['StartedAt'] │       │
│    → "2025-01-15T10:30:00.123456789Z"                │       │
│                                                       │       │
│  Docker-compose путь:                                 │       │
│    labels = container.labels                          │       │
│    compose_path = labels.get(                         │       │
│      'com.docker.compose.project.config_files'        │       │
│    )                                                  │       │
│    → "/opt/docker/my-app/docker-compose.yml"         │       │
│    → dirname() → "/opt/docker/my-app"                │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  8. МАППИНГ СТАТУСА                                   │       │
│                                                       │       │
│  Docker status    →    App status                     │       │
│  ─────────────────────────────────                    │       │
│  "running"        →    "online"                       │       │
│  "exited"         →    "offline"                      │       │
│  "paused"         →    "maintenance"                  │       │
│  "restarting"     →    "restarting"                   │       │
│  "created"        →    "offline"                      │       │
│  "dead"           →    "offline"                      │       │
│  "Up 2 hours"     →    "online"                       │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  9. ОБОГАЩЕНИЕ ДАННЫМИ EUREKA (опционально)           │       │
│                                                       │       │
│  Условие: EUREKA_DISCOVERY_ENABLED=true && port != None│      │
│                                                       │       │
│  eureka_client.find_app_by_ip_port(server_ip, port)   │       │
│                                                       │       │
│  Если найдено совпадение в Eureka:                    │       │
│    metadata["eureka_registered"] = True               │       │
│    metadata["eureka_instance_id"] = "192.168.1.100:my-app:8080"│
│    metadata["eureka_app_name"] = "MY-APP"             │       │
│    metadata["eureka_status"] = "UP"                   │       │
│    metadata["eureka_url"] = "http://..."              │       │
│    metadata["eureka_health_url"] = "http://.../health"│       │
│    metadata["eureka_vip"] = "my-app"                  │       │
│                                                       │       │
│  Если не найдено:                                     │       │
│    metadata["eureka_registered"] = False              │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  10. СОЗДАНИЕ ApplicationInfo                         │       │
│                                                       │       │
│  ApplicationInfo(                                     │       │
│    name = container_name,       # "my-app"            │       │
│    version = tag,               # "v1.2.3"            │       │
│    status = mapped_status,      # "online"            │       │

## 3. Сканирование Eureka приложений

### Источники данных

| Данные | Источник | API Endpoint |
|--------|----------|--------------|
| Список приложений | Eureka REST API | `GET /eureka/apps` |
| Instance ID | Response JSON | `instance.instanceId` |
| IP адрес | Response JSON | `instance.ipAddr` или из instanceId |
| Порт | Response JSON | `instance.port.$` |
| Статус | Response JSON | `instance.status` |
| Health URL | Response JSON | `instance.healthCheckUrl` |
| Метаданные | Response JSON | `instance.metadata` |

### Детальная схема сканирования Eureka

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      EurekaDiscoverer.discover()                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  1. ПРОВЕРКА ДОСТУПНОСТИ                                                     │
│                                                                              │
│     if not self.enabled or not self.client:                                 │
│         return []                                                            │
│                                                                              │
│     Проверяется: EUREKA_DISCOVERY_ENABLED=true                               │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  2. ЗАПРОС К EUREKA API                                                      │
│                                                                              │
│     GET http://{EUREKA_HOST}:{EUREKA_PORT}/eureka/apps                      │
│     Headers: Accept: application/json                                        │
│                                                                              │
│     Response структура:                                                      │
│     {                                                                        │
│       "applications": {                                                      │
│         "application": [                                                     │
│           {                                                                  │
│             "name": "MY-SERVICE",                                            │
│             "instance": [                                                    │
│               {                                                              │
│                 "instanceId": "192.168.1.100:my-service:8080",              │
│                 "ipAddr": "192.168.1.100",                                  │
│                 "port": {"$": 8080, "@enabled": "true"},                    │
│                 "status": "UP",                                              │
│                 "homePageUrl": "http://192.168.1.100:8080/",               │
│                 "healthCheckUrl": "http://.../actuator/health",            │
│                 "metadata": {...}                                           │
│               }                                                              │
│             ]                                                                │
│           }                                                                  │
│         ]                                                                    │
│       }                                                                      │
│     }                                                                        │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  FOR EACH app IN applications:                                               │
│    FOR EACH instance IN app.instances:                                       │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
        ┌───────────────────────────┴───────────────────────────┐
        │                                                       │
        ▼                                                       │
┌───────────────────────────────────────────────────────┐       │
│  3. ИЗВЛЕЧЕНИЕ IP АДРЕСА                              │       │
│                                                       │       │
│  Приоритет 1: Из instanceId                           │       │
│  ─────────────────────────────────────────            │       │
│  instanceId = "192.168.1.100:my-service:8080"        │       │
│  ip = instanceId.split(":")[0]                        │       │
│  → "192.168.1.100"                                    │       │
│                                                       │       │
│  Важно для Docker: instanceId часто содержит          │       │
│  реальный IP хоста, а ipAddr может содержать          │       │
│  внутренний Docker IP (172.17.x.x)                    │       │
│                                                       │       │
│  Приоритет 2: Из поля ipAddr (fallback)               │       │
│  ─────────────────────────────────────────            │       │
│  ip = instance.ipAddr                                 │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  4. ИЗВЛЕЧЕНИЕ ПОРТА                                  │       │
│                                                       │       │
│  port_data = instance.port                            │       │
│                                                       │       │
│  Если int:                                            │       │
│    port = port_data                                   │       │
│                                                       │       │
│  Если dict (Eureka формат):                           │       │
│    {"$": 8080, "@enabled": "true"}                   │       │
│    port = port_data["$"]                              │       │
│                                                       │       │
│  Результат: port = 8080                               │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  5. ИЗВЛЕЧЕНИЕ ВЕРСИИ ИЗ МЕТАДАННЫХ                   │       │
│                                                       │       │
│  metadata = instance.metadata                         │       │
│                                                       │       │
│  Поиск версии в полях (по приоритету):                │       │
│    - metadata["version"]                              │       │
│    - metadata["app.version"]                          │       │
│    - metadata["application.version"]                  │       │
│    - metadata["build.version"]                        │       │
│    - metadata["implementation.version"]               │       │
│                                                       │       │
│  Результат: version = "2.0.1" или "unknown"           │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  6. МАППИНГ СТАТУСА                                   │       │
│                                                       │       │
│  Eureka status    →    App status                     │       │
│  ─────────────────────────────────                    │       │
│  "UP"             →    "online"                       │       │
│  "DOWN"           →    "offline"                      │       │
│  "STARTING"       →    "starting"                     │       │
│  "OUT_OF_SERVICE" →    "maintenance"                  │       │
│  "UNKNOWN"        →    "unknown"                      │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        ▼                                       │
┌───────────────────────────────────────────────────────┐       │
│  7. СОЗДАНИЕ ApplicationInfo                          │       │
│                                                       │       │
│  ApplicationInfo(                                     │       │
│    name = app_name,            # "MY-SERVICE"         │       │
│    version = version,          # "2.0.1"              │       │
│    status = mapped_status,     # "online"             │       │
│    start_time = "unknown",     # Eureka не предоставляет│     │
│    metadata = {                                       │       │
│      "source": "eureka",                              │       │
│      "instance_id": "192.168.1.100:my-service:8080", │       │
│      "ip": "192.168.1.100",                           │       │
│      "port": 8080,                                    │       │
│      "home_page_url": "http://...",                   │       │
│      "eureka_status": "UP",                           │       │
│      "vip_address": "my-service",                     │       │
│      "health_check_url": "http://.../actuator/health",│       │
│      "status_page_url": "http://.../actuator/info",   │       │
│      "eureka_metadata": {...}                         │       │
│    }                                                  │       │
│  )                                                    │       │
└───────────────────────────────────────────────────────┘       │
                        │                                       │
                        └───────────────────────────────────────┘

                    ┌───────────────────────────────┐

| status | str | Статус (online/offline/...) | svcs -Ho state |
| start_time | str | Время запуска | svcs -Ho stime |
| pid | int | PID процесса | svcs -p -H |
| port | int | HTTP порт | server.xml или netstat |
| log_path | str | Путь к логам | Resolve симлинка logs/ |
| distr_path | str | Путь к артефакту | Resolve симлинка в htdoc |
| artifact_size_bytes | int | Размер артефакта | stat() |
| artifact_type | str | Тип (war/jar/directory) | Расширение файла |
| app_path | str | Путь к приложению | /site/app/{name} |
